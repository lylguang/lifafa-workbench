# 口播视频：配音、发布与内容安排交互细节

> 历史设计/验收记录，包含当时的方案与限制，不作为当前使用指南。当前入口见[文档索引](README.md)和[快速开始](quickstart.md)。

2026-09-17。实现位于能力包自身的 `client.js` 与媒体、发布、安排三个 host，通过 `gateway.mjs` 使用现有能力包工作区和凭据边界。

## 配音 / 字幕

- 「连接配置」使用模块强调色并显示「待配置 / 已连接」，未配置时额外突出边框。
- 新建任务默认勾选「同时生成字幕」，可取消。`startAudioTask` 在请求未指定 `subtitleEnabled` 时也默认开启，旧任务不会被补跑。
- 音频保存并同步项目、标记成功后，再启动该音频任务的字幕对齐。自动字幕沿用创建配音时的服务提供方。
- 字幕提交失败或执行失败只写入 `subtitle.status/error`；已完成音频和配音成功状态保留。页面仍可试听、单独重试字幕。

## 发布

- 「封面生图」显示连接状态并突出待配置入口。
- 卡片和抽屉中的视频按钮打开原生 `dialog` 播放器，支持关闭按钮、Escape、点击遮罩，关闭后还原焦点并卸载视频。
- 列表不拉取整段视频。发布卡优先使用封面，无封面则取视频首帧；运行历史使用小尺寸视频首帧。`readPublishAsset(kind: 'thumbnail')` 使用原有安全路径校验，在主机侧生成最长边 480px 的 JPEG，缓存按文件版本失效，最多两路并发提取。
- 发布抽屉分为成片、文案资料、横竖封面、最近生成记录，保留底部保存操作。成片和横竖封面分别提供下载，文件名包含标题和素材类型；视频也可从播放器下载。
- 内容安排跳转时传递项目 ID，发布页选中该项目所属账号并打开对应资料抽屉。

## 内容安排

- 定时任务的「运行详情」展示该任务的所有轮次；页面运行历史按当前账号展示。
- 每轮显示触发时间与方式、状态、深度、完成条数、耗时、产出缩略图和条目状态。已通过质检且媒体仍可用的成片提供「去发布页核对资料」。
- 执行过程默认折叠；只在展开该轮时请求完整阶段详情，执行中的详情持续刷新。关闭查看不会停止任务。
- 支持名称/标题/执行信息搜索、执行状态与触发方式筛选，以及每页 8/20/50 轮分页。切换条件回到首页；只有当前页返回媒体摘要。
- `listScheduleRuns` 是按页查询入口；`listSchedules` 仅返回定时任务配置、最新一轮及活动轮次摘要。取消原先 100 轮的存储截断，避免新运行覆盖现存历史；旧版本已经删除的记录无法恢复。
- 「取消编辑，恢复为新建」与「保存修改」相邻。

## 验证

- `npm test`：语法、Profile、能力包 Profile 及 276 项测试全部通过。
- 新增覆盖自动字幕成功、字幕提交/执行失败隔离、显式关闭字幕、125 轮历史保留和组合筛选分页、缩略图实际生成与失败恢复。
- 使用真实前端组件与隔离 RPC 示例数据进行浏览器检查：默认勾选、弹窗播放/关闭、视频和封面下载、默认折叠、按需展开、状态筛选、翻页、对应项目跳转、编辑按钮相邻、暗色与 390px 窄屏。未调用真实 TTS/ASR/生图服务。
