# 运行数据目录与原生附件

实施日期：2026-09-16。本文是当前运行数据布局的依据；早期设计和验收文档中的旧路径只保留为历史记录。

## 目录契约

产品默认持久化运行数据以 `lwb/local/` 为唯一入口，源码与运行数据分离。

```text
lwb/local/
├── packs.json                          # 外部包登记与加载状态
└── dsh-home/
    ├── settings.yaml                   # DSH 全局设置
    ├── .credentials.yaml               # DSH 管理的凭据
    ├── sessions/                       # 原生会话和审计
    ├── storages/                       # 原生工作区等状态
    ├── attachments/                    # 原生图片、文件附件
    └── profiles/lwb/
        ├── settings.yaml              # Profile 设置与能力包业务配置
        └── pack-state/
            ├── ownership.json         # 能力包工作区及内部会话归属
            ├── workspaces/spoken-video/
            │   └── data/
            │       ├── signals.json
            │       ├── topic-profile.json
            │       ├── topic-generations.json
            │       ├── script-generations.json
            │       ├── schedules.json
            │       ├── projects/      # 稿件、阶段产物和项目媒体
            │       └── …              # 配音、视频、发布任务及其媒体
            └── retained/              # 清空能力包时保留的可恢复副本
```

文件按需创建；空白实例不预置账号、会话或能力包业务数据。能力包的根目录由宿主分配，口播模块通过同一 `spokenVideoDataPath()` 函数定位 `data/`。普通工作区的源码和用户要求 Agent 创建的文件仍属于用户自己的目录，不属于产品运行状态。

测试可通过 `LWB_DSH_HOME`、`LWB_PACK_REGISTRY` 指定独立临时位置。自动化测试使用退出后删除的系统临时目录；手动巡检使用 `lwb/local/verification/`，结束后删除，不能在项目根目录建立新的数据入口。

## 普通对话附件

上传、上传回执、待发送附件、消息绑定、历史展示和持久化全部由 DSH 原生服务负责。LWB 不再提供上传模式选择，不注册 `lwbFiles` RPC，不覆盖附件栏或用户消息渲染器，也不修改原生 Session 的 prompt 方法。

已移除旧 `file-intake-*.mjs`、浏览器兼容组件、旧模式开关、专用依赖链接及其测试。Profile 检查继续要求原生 `file-upload` 和 `ui-attachment` 模块存在，并检查旧接管逻辑没有重新装配。

## 调度与工作区隔离

信号自动采集、任务中断恢复和定时内容生产只处理宿主指定的能力包工作区。旧的跨普通工作区索引及读写回退已删除；不再生成 `spoken-video-schedule-workspaces.json`。

内容存储和调度器会拒绝与其绑定目录不一致的上下文。业务目录仍检查符号链接，避免将数据写入另一个工作区。卸载、重新加载、清空和保留副本仍以整个能力包工作区为单位。

## 本次切换边界

本次是在用户已经要求清空产品数据、且当前实际实例没有能力包业务数据的前提下切换路径。没有保留旧路径回退或自动迁移；旧附件消息和旧业务目录不再由当前代码兼容读取。

项目根目录和能力包内部均不再创建 `.lwb/`。Git 不再忽略该名称，意外产生的旧目录可以在状态检查中被发现。历史文档提及旧名称不表示仍存在运行依赖。

## 验证

- `npm test`：语法、基础 Profile、能力包 Profile 及业务回归；单独执行单元测试使用 `npm run unit:test`。
- 本次最终回归：246 项全部通过，0 失败、0 跳过。测试数量随旧上传专用测试的删除及新目录隔离测试的补充而调整。
- 更新账号、信号、项目、媒体、发布和定时任务测试中的磁盘断言，使其读取新 `data/` 路径。
- 工作区集成测试验证账号与项目共享 `data/`、重新读取保留结果、越界上下文被拒绝，以及符号链接不能将业务写入其他包目录。
- 隔离浏览器实测普通文件上传、待发送卡片与移除：原始字节存入 DSH `attachments/v1/files/` 和 `file-objects/`，普通工作区保持空目录。
- 原生附件随消息提交到本地模拟模型，模型请求包含文件引用；收到回复后刷新，历史消息中的附件卡片与回复仍正常显示。
- 隔离浏览器实测能力包加载、账号创建与刷新恢复，专属工作区只有 `data/` 子目录，没有旧隐藏目录或跨工作区索引。

浏览器和模拟模型仅用于验证原生上传、界面与数据接线，不代表真实媒体供应商已通过生产验收。验收产生的本地测试数据在完成后清理，实际实例保留空白状态，供用户从头测试。
