# 01 产品定位与总体架构

> **当前架构（2026-09-21）**：基于锁定的 DSH `dsh-v0.1.6-alpha.1`，提供“对话”“场景能力包”和“设置”。通过动态加载的独立包持续扩展业务场景；口播视频内容创作是第一个已实现的业务包。

## 产品边界

老傅工作台（LWB）建立在 DeepSeek Harness（DSH）之上，不维护第二套聊天、模型路由或权限运行时。工作台核心提供通用基础能力，场景包拥有自己的页面、业务流程和存储；新增业务优先通过包扩展。当前市场发现本机目录和已注册包，尚无在线下载或自动更新服务。

| 模块 | 用户看到的对象 | 事实源 |
|---|---|---|
| 对话 | 普通 DSH 会话、工作区历史与官方 Conversation | DSH Session、工作区、模型、工具、事件与审计 |
| 场景能力包 | 已挂载包目录、菜单与领域工作流 | LWB Pack Registry；本机安装表与 DSH Loader |
| 设置 | 唯一的产品设置入口，承接 DSH 原生运行时设置 | LWB 设置页负责产品壳；DSH 原生设置页负责模型、凭据、权限和审批 |

## 职责分层

```text
LWB 产品壳
├─ 对话：普通 Session 列表、工作区与官方 Conversation
├─ 场景能力包：宿主目录、菜单注入与独立包页面
└─ 设置：唯一入口；承接 DSH 原生运行时设置
       │
       ├─ LWB：页面状态、能力包壳、历史会话隔离索引
       └─ DSH：Session、模型、凭据、工具、权限、审批与原始审计
```

LWB 只在 Profile / Bundle 层适配 DSH 接缝，不改写 DSH 源码、Session 格式、模型协议或权限机制。

## 关键不变量

1. 对话模块完全使用 DSH 原生 Session、工作区和归档状态；LWB 不维护第二套会话分类或投影。
2. 新建对话完全由 DSH 的当前模型和权限配置决定；LWB 不维护第二套默认模型、服务商、语言或主题配置页，DSH 原生设置仅从 LWB“设置”模块进入。
3. 基础 Profile 不引用任何具体场景包；已安装包只能由宿主实际挂载目录展示，浏览器本地状态不能伪造生命周期或菜单。
4. 设置模块是唯一的配置入口；服务商、模型、凭据、语言、主题、工具权限和审批必须继续经过 DSH 的原生边界。
5. 不加载 DSH 实验 Agent Team 包，也不保留产品私有补丁；上游升级只适配当前 LWB 产品层。
