# 配音、字幕与视频的衔接

> 历史设计/验收记录，包含当时的方案与限制，不作为当前使用指南。当前入口见[文档索引](README.md)和[快速开始](quickstart.md)。

已保存的稿件可以进入配音，不再要求额外的人工确认记录。旧 `scriptApproval` 字段及接口保留兼容，但不作为配音产物提交门槛。稿件改版仍会使下游项目产物失效。

音频任务保存自己的文本快照、音频和字幕。项目当前产物供「视频 / 预览」选择；任务生成成功与项目同步失败需要分别展示，不能丢弃已经成功生成的音频。

- 新配音完成后，先尝试同步项目，再发布任务完成状态。只同步与项目当前稿件正文、版本一致的音频。
- 同步失败记录 `projectSyncError` 或 `subtitleSyncError`，在配音任务卡内展示，并提供「同步到视频」。该操作调用 `syncAudioTask`，只使用本地已有产物，不调用配音或字幕服务。
- 历史任务补同步不会覆盖项目已采用的其他配音。音频不匹配当前稿件时仍保留独立任务，并说明原因。
- 部分失败可能已经复制媒体文件。重试会校验并复用内容完全一致的文件；不同内容或非普通文件被拒绝，禁止覆盖。
- 重复同步不会重新提交已生效的同一音频、字幕，避免无故使视频等下游产物失效。字幕校对后可同步新版本，依据当前配音文件和稿件版本校验，不再用第一次配音同步后的项目总版本拦截后续字幕更新。
- 配音与字幕同步完成后刷新项目状态；视频页继续按账号展示具有稿件和配音产物的项目。字幕可选，字幕生成失败不阻止已完成配音的项目进入视频制作。

验证覆盖：未确认稿件、新任务自动同步、历史音频和字幕恢复、残留媒体文件复用、重复同步、字幕校对后更新、改稿/换配音保护、文件缺失后的重试，以及关闭字幕的视频制作。
