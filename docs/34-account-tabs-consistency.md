# 34 账号 Tab 一致性（2026-09-17）

> 历史设计/验收记录，包含当时的方案与限制，不作为当前使用指南。当前入口见[文档索引](README.md)和[快速开始](quickstart.md)。

选题、写稿、配音 / 字幕、视频 / 预览、发布和内容安排统一使用 `AccountTabs`，配音的选稿抽屉也使用同一组件。

- Tab 仅显示账号名称，不附加业务数量；不同模块的选题、执行任务、成片数量不混入账号切换入口。
- 活跃账号沿用账号库顺序，默认账号显示带“默认账号”提示的圆点，末位固定为“通用（无账号定位）”。没有数据的活跃账号仍可选择。
- 保留各模块主题色、选中态以及内容安排编辑时禁用账号切换的行为。
- 写稿选题数量、发布成片数量保留在对应列表标题中。归档账号的历史内容仍沿用原有入口，发布页的“已归档”是独立提示，不是账号 Tab。

## 作用范围

| 模块 | 账号 Tab 的范围 |
|---|---|
| 选题 | 左侧新建任务的账号定位；右侧明确标记“选题任务 · 全部账号” |
| 写稿 | 左侧可写稿选题与新建目标；右侧明确标记“写稿任务 · 全部账号” |
| 配音 / 字幕 | 稿件选择、任务列表、任务状态计数与分页 |
| 视频 / 预览 | 可制作稿件与视频任务 |
| 发布 | 成片列表 |
| 内容安排 | 新建任务归属与右侧定时任务；编辑期间不可切换 |

## 配音筛选与分页

`listAudioTasks` 接受 `accountId` 或 `general: true`。服务端根据来源项目的账号归属筛选后，再处理状态、渠道、搜索、排序和分页；状态计数基于该账号全部任务，列表总数基于当前筛选结果。无来源项目的手动任务、无账号项目及来源项目已不存在的任务归入通用，保持原前端分组规则。未提供账号条件的调用仍返回全部账号任务。

客户端不再对已分页结果二次按账号过滤。切换账号重置配音任务与选稿分页，旧请求结果不能覆盖新账号列表；顶部音频任务数采用当前账号总数，而非当前页卡片数。

## 验证

- `npm test`：272 项全部通过，含新增的多账号分页、状态计数、搜索、通用任务、空账号和无筛选调用回归。
- 浏览器核对六个主页面的账号名称、通用文案、默认圆点和选中状态。
- 本次检查时，本地运行进程仍持有旧版媒体服务；后端筛选更新需要重启服务后生效。浏览器加载到新页面代码不代表服务端模块已重新加载。
