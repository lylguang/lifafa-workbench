# 安装与故障排查

先确认命令在项目根目录执行，并保留终端中最早出现的错误。以下适用于当前锁定的 DSH 版本；新版本可能有不同要求。

## 常见问题处置手册（Windows 生产环境）

按「现象 → 真实原因 → 下一步动作」组织，来自本机生产环境的真实故障记录。

### 鉴权与 token 过期

- **现象**：浏览器打开 `http://127.0.0.1:4173/` 提示 `dsh web authentication required`；或昨天能打开今天打不开。
- **真实原因**：带鉴权 token 的完整地址（`http://127.0.0.1:4173/?token=...`）只在进程内存里，每次重启都会变化，裸域名不含 token。
- **下一步**：双击 `打开工作台.cmd`——它读取暂存目录下的 `workbench-url.txt` 直接打开最新地址。源码方式运行则回到启动终端复制最新一行带 `token=` 的完整 URL。token 不适用时（换了启动方式）重启服务再取。

### 端口占用 / 「启动失败」其实是已在运行

- **现象**：再次双击 `启动工作台.cmd` 或手动跑 `npm run dev` 报 `EADDRINUSE`。
- **真实原因**：4173 已有实例在跑，第二个实例启动才会死，看起来像启动失败；其实第一个实例的页面仍然有效。
- **下一步**：启动脚本会先探测 4173 并直接提示复用；手动运行时确认 `http://127.0.0.1:4173/` 能访问即可，或换端口 `npm run dev -- --port 4174`。

### 配音报「凭据未配置」但明明配过 / 「Invalid API key」怪音色

- **现象**：配音失败提示凭据缺失；或换个启动方式就报认证失败，且错误指向音色。
- **真实原因**：系统对话模型的凭据不会自动成为媒体凭据（「配音/字幕 → 连接配置」是独立的一套）；定时任务的配音渠道曾被硬编码回云端默认值，连接切到桥接后定时轮仍打百炼（2026-09-30 已修为跟随连接配置）。
- **下一步**：到「配音/字幕 → 连接配置」重新保存所选供应商的媒体凭据；确认配置确实落在当前使用的供应商分支上；认证失败提示现在会直接指出该改哪里，按提示改，不要去换音色。

### 媒体 Key 在口播视频包配好了，切到情感故事号仍提示未保存

- **现象**：在「口播视频内容创作」包里配好了媒体服务 API Key，切到「情感故事号」包仍显示「还没保存媒体服务 API Key」。
- **真实原因**：媒体凭据按包隔离（宿主给每个包的凭据引用加包命名空间前缀，`pack-workspaces.mjs` 的 `packCredentialRef`），两个包各存一份 Key，这是包隔离设计不是丢配置。环境变量名两个包相同（如 `LWB_SPOKEN_VIDEO_SCITIGER_BASE_URL`），媒体服务地址是共享的。
- **下一步**：到「情感故事号 → 配音 / 字幕 → 打开连接配置」再保存一次媒体 Key；媒体服务地址不用改。

### 封面生图提示未配置 / 「缺少服务地址」

- **现象**：封面生成失败提示未配置，或「缺少服务地址」。
- **真实原因**：封面渠道在「发布 → 封面生图」独立配置；自定义渠道的「缺少服务地址」判定曾只看表单状态、误伤从未打开过表单的用户（`customImageDefaults` 预设里本来就带可用地址，2026-10-15 已修为回落预设）；「模型不存在」一类服务端拒绝曾被误报成「不可访问」，让人去查网络而真正该查的是模型名（已分三支：参数拒绝原样透出、超时才提醒可能已计费）。
- **下一步**：到「发布 → 封面生图」选择渠道并保存；自定义渠道填地址（OpenAI 兼容协议填 Key 即可用，默认预填萝卜Ai TT Image 2.5）；报「模型不存在」时核对模型名拼写，报「可能已计费」时先去服务商后台确认、**不要重复提交**。

### FFmpeg / 渲染浏览器找不到

- **现象**：视频阶段报 `ffmpeg` / `ffprobe` 不存在，或找不到渲染浏览器。
- **真实原因**：交付包自带两者（「运行环境/ffmpeg」与「浏览器/chrome-headless-shell-win64」），入口脚本会把它们置到 PATH 最前；只有绕过入口脚本直接 `npm run dev` 时才依赖系统安装。渲染浏览器必须走短路径（Windows MAX_PATH 260，渲染工作区路径本身已近 300 字符）。
- **下一步**：改用 `启动工作台.cmd` 启动。源码方式运行时：在同终端验证 `ffmpeg -version`；渲染浏览器设 `LWB_REMOTION_BROWSER_EXECUTABLE` 为 Chrome/Edge 的 `chrome.exe` 绝对路径，或跑 `npx --no-install remotion browser ensure`。

### 字幕漂移 / 字幕比配音早出现

- **现象**：字幕提前上屏（最多实测 15 秒）或渐进漂移。
- **真实原因**：云端 ASR 时间戳滞后是已知问题，上游按字数估算的上屏时间提前 0.4–1.0 秒；本仓库两条字幕路径都跑对齐守卫（段级句级时序地面真值 + 锚点校验），重对齐后误差均值 7.10s → 1.61s，但守卫不是无限精度。
- **下一步**：在任务里单独重试字幕（音频保留，不必重新付费配音）；若漂移仍明显，检查稿件是否大量数字/英文混排，向 Issues 提供脱敏稿件与 SRT。

### 渲染完成但发布页没有成片 / 「通过渲染但未过质检」

- **现象**：视频渲染完成，但发布页看不到成片，或任务报「未通过技术质检/审片」。
- **真实原因**：通过渲染不等于通过全部检查——技术质检（含字幕口径、抽帧核对、内容安全扫描）与独立审片是独立关口，失败任务不会被当作合格成片提交；这是设计行为。
- **下一步**：到执行详情查看具体未过的检查项与失败原因；存量成片可用「补做技术质检」而无需重渲；按失败原因修稿件或场景表后重跑该阶段。

### 定时任务没跑 / 轮次消失

- **现象**：到点没有动静，或「今天的任务没跑」。
- **真实原因**（历史上 33 轮失败 24 轮的归类）：密钥失效、引擎不可达、超时误杀、重启打断、同分钟到期抢跑被吞——本仓库已用五道闸门 + 多任务排队 + 断点续跑（interrupted）+ 依赖自愈四层系统性处置；但**关闭工作台服务后定时任务必然不跑**（浏览器关掉不影响，服务退出才影响）。
- **下一步**：先确认工作台服务在运行（保活计划任务 LWBKeepAlive 负责拉起）；打开「内容安排」查看轮次记录与失败分类，失败弹窗正文优先显示「该做什么」（remedy），按它执行；`interrupted` 状态（橙色）的轮次会自动续跑，不用手动干预；`blocked`（红色）需要先去改配置。

### 发布停在确认步

- **现象**：发布任务最后停在浏览器窗口不动。
- **真实原因**：默认「发布前确认」是安全设计——视频上传与资料填写自动完成，最后一步由人在浏览器窗口点确认；同时自动声明「内容由AI生成」、封面/标题已按真机探针校准填好。
- **下一步**：在弹出的浏览器窗口核对标题（≤30 字）、描述、封面与声明后点击发布；若窗口里报错（如「平台未弹出文件选择器」），把截图与发布记录发给 Issues——适配器设计为「退化为截图报错而非点错」，不会发错内容。

### 信号源 fetch failed

- **现象**：信号页采集失败、fetch failed。
- **真实原因**：公开站点可能限流、改接口或被网络环境拦截；采集失败不影响其他可用渠道参与选题。
- **下一步**：查看该来源的采集记录确认是单一来源还是全部失败；单一来源先停用该来源稍后重试；全部失败检查本机网络/代理。不要为了采集问题去改上游锁定版本。

### 显存 / 内存不释放

- **现象**：跑完视频后系统卡顿，空闲显存/内存很低。
- **真实原因**：本地引擎（封面生图 ComfyUI 约 5.8 GB 内存 + 大量显存、字幕引擎约 400 MB）是常驻进程；2026-10-10 起桥接已做两级自动回收：空闲 5 分钟卸模型还显存、空闲 20 分钟停进程还内存（探测到任务在跑会推迟，宁可少释放也不打断）。
- **下一步**：到「配音/字幕」页顶部面板查看两个引擎的占用条，点「释放显存」或「停止」（下次任务自动拉起，等 30–40 秒）；若配音走云端（默认），本地引擎不在主链路上，直接停止无副作用。阈值可用 `LWB_BRIDGE_IMAGE_IDLE_MS / _IDLE_STOP_MS` 覆盖。

## 环境与安装

| 问题 | 检查与处理 |
|---|---|
| Node 版本不支持或 JSON import 报错 | 用 `node --version` 检查。使用 `^22.19.0 || >=24.0.0`，建议 Node.js 22 LTS 最新补丁；切换版本后重新安装依赖。 |
| `corepack: command not found` | 安装适配当前 Node 的 Corepack，例如 `npm install -g corepack`，确认 `corepack --version` 可运行后重试 `npm run setup`。上游脚本直接调用 `corepack pnpm`，不要求手动切换根目录包管理器。 |
| 原生依赖编译失败 | 检查本机编译器、Node 开发头文件及报错提到的构建工具。macOS 安装 Xcode Command Line Tools；其他系统按目标发行版安装 C/C++ 构建工具。 |
| 克隆、安装依赖或浏览器下载超时 | 检查到 GitHub、npm 注册表与下载地址的网络连接、代理和终端证书设置；不要通过修改上游锁定版本解决网络问题。 |
| `Missing vendored DSH checkout` 或 DSH 未构建 | 先执行 `npm ci`，再执行 `npm run setup`；`npm run dev` 不负责下载或构建上游。 |
| 更新后出现上游导出/模块解析错误 | 查看 `git -C vendor/deepseek-harness status --short`，确认没有人为源码改动。停止服务，把旧 `vendor/deepseek-harness` 移到仓库外备份，再执行 `npm run setup` 构建干净副本。不要删除业务数据。 |

## 页面访问与能力包

- **首次访问提示鉴权或连接失败**：从当前服务终端复制完整的带 `token` URL；旧进程的令牌可能不适用。可用 `npm run dev -- --no-open --port 4173` 明确端口。
- **端口被占用**：选择未占用端口，例如 `npm run dev -- --port 4174`，并使用新输出的地址。
- **没有看到口播菜单**：先进入「场景能力包」加载口播包。注册/发现与加载是两个步骤；无需为了使用能力包创建普通对话。
- **外部包不可用**：确认注册的源目录还存在，manifest、包名、版本和 host/client 入口匹配。源目录移动后，先卸载，再用 `npm run pack:remove -- pack-id` 移除旧登记，重新注册新路径。
- **卸载提示任务仍在停止**：等待在途任务结算后重试。维护数据前必须先完成卸载，不要直接移动运行中的业务目录。
- **改了 `.env` 却没有效果**：启动器不会自动读取该文件；请在启动 shell 中 `export` 变量，并重启服务。详见 [.env.example](../.env.example)。

项目定位是本机单用户工作台。远程部署、多人访问和公开互联网服务不属于当前快速开始的覆盖范围。

## 模型和媒体任务

| 现象 | 检查位置 |
|---|---|
| AI 任务提示缺少模型 | 到「设置 → 系统设置 → 模型」配置服务商、凭据与默认模型。能力包使用系统默认选择，不依赖普通对话的临时模型覆盖。 |
| 模型能聊天但写稿/视频失败 | 查看执行详情中的供应商错误、工具执行、结构化输出或上下文限制；视频审片需要图片输入能力。先用较短内容验证。 |
| 信号采集失败 | 检查该来源的采集记录和网络状态，必要时停用该来源。公开站点可能限流或更改接口；其他可用渠道仍可参与选题。 |
| 配音/字幕提示未配置 | 到「配音 / 字幕 → 连接配置」保存所选供应商的媒体凭据。系统对话模型凭据不会自动成为媒体凭据。 |
| 封面生成提示未配置 | 到「发布 → 封面生图」配置对应服务，确认图片模型可用。 |
| SciTiger 提示积分不足 | 检查供应商账户余额、模型权限与 API 区域/工作空间；充值或切换到已经配置可用的渠道后重试。 |
| `ffmpeg` / `ffprobe` 不存在 | 在启动服务的同一终端验证两个命令，安装 FFmpeg 并配置 PATH，重启服务。 |
| 找不到渲染浏览器 | 运行 `npx --no-install remotion browser ensure`，或设置 `LWB_REMOTION_BROWSER_EXECUTABLE` 为实际可执行文件绝对路径。 |
| 视频中文缺字 | 在运行主机安装可用的中文字体，确认视频工程指定的字体能够解析。 |
| 配音成功但字幕失败 | 音频保留，可在任务中单独重试字幕；不必为了字幕重新付费生成配音。 |
| 视频渲染完成但没有可发布成片 | 查看技术质检与独立审片结果。通过渲染不等于通过全部检查，失败任务不会被当作合格成片提交。 |

## 数据与反馈

卸载不会清除数据；清空会把原工作区移入可恢复副本。重新加载后，启用的信号源可能开始新采集，因此信号池再次出现内容不代表旧数据恢复。

如需报告问题，请到 [GitHub Issues](https://github.com/lylguang/lifafa-workbench/issues) 提供：系统与 Node 版本、当前 Git commit、执行命令或页面操作、预期和实际结果，以及脱敏后的最早错误。不要粘贴 API Key、鉴权 URL、完整运行目录或私人稿件。详细贡献流程见 [CONTRIBUTING.md](../CONTRIBUTING.md)。
