# 安装与故障排查

先确认命令在项目根目录执行，并保留终端中最早出现的错误。以下适用于当前锁定的 DSH 版本；新版本可能有不同要求。

## 环境与安装

| 问题 | 检查与处理 |
|---|---|
| Node 版本不支持或 JSON import 报错 | 用 `node --version` 检查。使用 `^22.19.0 || >=24.0.0`，建议 Node.js 22 LTS 最新补丁；切换版本后重新安装依赖。 |
| `corepack: command not found` | 安装适配当前 Node 的 Corepack，例如 `npm install -g corepack`，确认 `corepack --version` 可运行后重试 `npm run setup`。上游脚本直接调用 `corepack pnpm`，不要求手动切换根目录包管理器。 |
| 原生依赖编译失败 | 检查本机编译器、Node 开发头文件及报错提到的构建工具。macOS 安装 Xcode Command Line Tools；其他系统按目标发行版安装 C/C++ 构建工具。 |
| 克隆、安装依赖或浏览器下载超时 | 检查到 GitHub、npm 注册表与下载地址的网络连接、代理和终端证书设置；不要通过修改上游锁定版本解决网络问题。 |
| `Missing vendored DSH checkout` 或 DSH 未构建 | 先执行 `npm ci`，再执行 `npm run setup`；`npm run dev` 不负责下载或构建上游。 |
| 更新后出现上游导出/模块解析错误 | 查看 `git -C vendor/deepseek-harness status --short`，确认没有人为源码改动。停止服务，把旧 `vendor/deepseek-harness` 移到仓库外备份，再执行 `npm run setup` 构建干净副本。不要删除业务数据。 |

## 页面访问与能力包

- **首次访问提示鉴权或连接失败**：从当前服务终端复制完整的带 `token` URL；旧进程的令牌可能不适用。可用 `npm run dev -- --no-open --port 4173` 明确端口。
- **端口被占用**：选择未占用端口，例如 `npm run dev -- --port 4174`，并使用新输出的地址。
- **没有看到口播菜单**：先进入「场景能力包」加载口播包。注册/发现与加载是两个步骤；无需为了使用能力包创建普通对话。
- **外部包不可用**：确认注册的源目录还存在，manifest、包名、版本和 host/client 入口匹配。源目录移动后，先卸载，再用 `npm run pack:remove -- pack-id` 移除旧登记，重新注册新路径。
- **卸载提示任务仍在停止**：等待在途任务结算后重试。维护数据前必须先完成卸载，不要直接移动运行中的业务目录。
- **改了 `.env` 却没有效果**：启动器不会自动读取该文件；请在启动 shell 中 `export` 变量，并重启服务。详见 [.env.example](../.env.example)。

项目定位是本机单用户工作台。远程部署、多人访问和公开互联网服务不属于当前快速开始的覆盖范围。

## 模型和媒体任务

| 现象 | 检查位置 |
|---|---|
| AI 任务提示缺少模型 | 到「设置 → 系统设置 → 模型」配置服务商、凭据与默认模型。能力包使用系统默认选择，不依赖普通对话的临时模型覆盖。 |
| 模型能聊天但写稿/视频失败 | 查看执行详情中的供应商错误、工具执行、结构化输出或上下文限制；视频审片需要图片输入能力。先用较短内容验证。 |
| 信号采集失败 | 检查该来源的采集记录和网络状态，必要时停用该来源。公开站点可能限流或更改接口；其他可用渠道仍可参与选题。 |
| 配音/字幕提示未配置 | 到「配音 / 字幕 → 连接配置」保存所选供应商的媒体凭据。系统对话模型凭据不会自动成为媒体凭据。 |
| 封面生成提示未配置 | 到「发布 → 封面生图」配置对应服务，确认图片模型可用。 |
| SciTiger 提示积分不足，或百炼提示额度/权限错误 | 检查供应商账户余额、模型权限与 API 区域/工作空间；充值或切换到已经配置可用的渠道后重试。 |
| `ffmpeg` / `ffprobe` 不存在 | 在启动服务的同一终端验证两个命令，安装 FFmpeg 并配置 PATH，重启服务。 |
| 找不到渲染浏览器 | 运行 `npx --no-install remotion browser ensure`，或设置 `LWB_REMOTION_BROWSER_EXECUTABLE` 为实际可执行文件绝对路径。 |
| 视频中文缺字 | 在运行主机安装可用的中文字体，确认视频工程指定的字体能够解析。 |
| 配音成功但字幕失败 | 音频保留，可在任务中单独重试字幕；不必为了字幕重新付费生成配音。 |
| 视频渲染完成但没有可发布成片 | 查看技术质检与独立审片结果。通过渲染不等于通过全部检查，失败任务不会被当作合格成片提交。 |

## 数据与反馈

卸载不会清除数据；清空会把原工作区移入可恢复副本。重新加载后，启用的信号源可能开始新采集，因此信号池再次出现内容不代表旧数据恢复。

如需报告问题，请到 [GitHub Issues](https://github.com/ScarecrowFu/dsh-laofu-workbench/issues) 提供：系统与 Node 版本、当前 Git commit、执行命令或页面操作、预期和实际结果，以及脱敏后的最早错误。不要粘贴 API Key、鉴权 URL、完整运行目录或私人稿件。详细贡献流程见 [CONTRIBUTING.md](../CONTRIBUTING.md)。
