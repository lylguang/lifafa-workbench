## 0. 背景

用户三个问题：① 内容流水线是否应放到信号池概览下方；② 信号池概览占的高度是否太多；③ 信号卡片与弹窗能否进一步美化，更贴合「信号」这一产品概念。

## 1. 现状度量（首屏垂直占用，按现行 CSS 实测推算）

| 区块 | 近似高度 | 说明 |
|---|---|---|
| `sv-pipestrip` 内容流水线 | ~44px | 9 阶段胶囊 + 「N 条在制」 |
| `sv-signal-hero` 信号池概览 | ~195–200px | 上下 padding 36 + 标题区（kicker+标题+副题）~62 + 四格统计 ~62 + 内 gap |
| `sv-tabs` 信号板/来源管理 | ~38px | 下划线式 Tab |
| 条件 `sv-note`（今日无新信号时） | ~36px | |

**首屏元信息合计约 280px**：900px 视口下，信号卡片只能露出约两行。而信号页的核心动作是「浏览信号、评估信号」——元信息（流水线、概览、Tab）先吃掉三成首屏，是观感「头重脚轻」的根因。结论：用户直觉成立。

另一个结构性问题：流水线放在最顶部，是 `PackFrame` 八页统一挂载位置的结果（v2.3 一致性决策），不是信号页信息层级的要求。流水线是**生产视角**（九阶段各几条在制），信号页的主视角是**情报视角**，两者主次颠倒。

## 2. 三个问题的判断

1. **流水线应下移 ✅**。概览成为页面第一视觉主体；流水线移到概览下方（Tab 行附近亦可），作为「下游去向」的注脚——信号的自然叙事是「情报进来 → 评估 → 送入流水线」，流水线在下方正好接住「送入选题」的动线。注意：`PackFrame` 为八页共用，信号页用可选 prop（如 `pipelineBelow`）单独定制，不波及其它七页。
2. **概览过高 ✅，压缩为单行命令条**。现 hero 三段垂直堆叠（标题区 / 统计 / 动作）。目标形态「概览命令条」≈64–72px：左 = 模块 kicker + 「信号板」标题 + 呼吸 live 胶囊；中 = 四项统计内联（数字 18–20px/800，标签 10px，竖线分隔）；右 = [采集 N 个来源] 主按钮 + [导入 AI 日报] [来源管理] 次按钮。一次性回收 ~130px 首屏。
3. **卡片与弹窗美化 ✅，方向＝把「信号要素」可视化**（见 3、4 节）。

## 3. 信号卡片重塑（卡片 = 一条可被快速评估的情报）

现状问题：全部信息是纯文本行，无视觉锚点；`sv-kpi` 把评分/排名/热度/标签堆成一行小字；动作区四个同款文字按钮（原文/送入选题/收藏/忽略）层级不清；来源卡与信号卡视觉语言接近，「来源」与「信号」两种实体区分不足。

信号五要素 → 可视化载体：

| 要素 | 现状 | 目标 |
|---|---|---|
| 来源/平台 | 文本 `· 抖音` | 平台 glyph 徽标（彩色圆角方块 + 首字，如 抖/B/公/红/视；热榜系用蓝） |
| 强度 | `评分 82` 小字 | 评分可视化短进度条 + 排名徽标（#1 深色实底、Top3 渐变描边）+ 热度火焰数字 |
| 时效 | `2026-09-03 09:00` 绝对时间 | 相对时间（2 小时前）+ 今日新增带 NEW 呼吸点 |
| 内容 | 标题 15px 单行 + 摘要 2 行 | 标题 14px/700 两行 clamp，摘要 12px 两行，标签改 chip |
| 动作 | 四个平级文字按钮 | 主＝「送入选题」实色小按钮；次＝原文/收藏/忽略 ghost 图标按钮，hover 显现 |

该卡片组件同时作为抽屉列表项复用（抽屉窄，摘要收敛为 1 行）。

## 4. 弹窗（信号抽屉）重塑

现状问题：560px 右抽屉；头部仅「SOURCE DETAIL + 名称 + 关闭」；来源动作（立即采集/设置/停用）挤在头部下方；列表无筛选/搜索/排序，`limit: 200` 全量平铺，「今日新增 / 更早」两个纯文本分组标题无粘性。

目标结构（自上而下）：

1. **粘性来源头**：glyph + 来源名 + 状态徽章 + 三格迷你统计（今日新增/活跃/已收藏）+ 动作（立即采集=主，设置/停用=次）。
2. **工具行**：筛选 chips（全部 / 今日 / 已收藏 / 已忽略）+ 搜索框（标题/摘要本地过滤）。
3. **分组小标题** sticky（今日新增 N / 更早 N）。
4. **列表项** = 第 3 节信号卡片组件。
5. 抽屉宽度 560 → 640px，给卡片两行标题与动作区留空间。

AI 日报导入抽屉、来源设置抽屉维持现状（表单性质，非本次重点）。

## 5. 页面骨架目标形态

```text
┌ 概览命令条（≈64px）：信号板 · live 胶囊 │ 今日新增 24 · 在位 17/18 · 异常 0 · 3 分钟前 │ [采集] [导入] [管理] ┐
├ Tab：信号板 / 来源管理 ──────────────────────────────────────────────────────────── ┤
├ 内容流水线（瘦条，下移）：9 阶段胶囊 + N 条在制 ──────────────────────────────────── ┤
├ 链路 A 分组卡片（新信号卡）…  链路 B AI 内容日报 5 平台卡 ─────────────────────────── ┤
```

## 6. 落地优先级

- **P0（改动小、收益大）**：hero 压缩为命令条；流水线下移（信号页单独定制 PackFrame）。
- **P1**：信号卡片组件重塑（含排名徽标/评分条/平台 glyph/动作分层）；抽屉加粘性来源头 + 筛选 + 搜索；抽屉列表复用卡片组件。
- **P2**：平台色板与暗色主题覆盖、hover 动效微调、NEW 呼吸点等细节。
