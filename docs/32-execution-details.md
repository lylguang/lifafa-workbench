# 口播创作：统一执行详情

2026-09-16

选题、写稿、账号定位、配音字幕、视频制作、发布资料与内容安排中的具体任务，共用“执行概览 / 执行过程 / 结果产物”详情面板。打开详情只读取任务和会话；关闭面板只停止观察，不取消生成。

## 各模块展示什么

| 模块 | 过程来源 | 结果 |
| --- | --- | --- |
| 账号定位 | 独立 DSH 子会话，新增账号完善执行历史 | 账号字段建议及说明 |
| 信号采集 | 采集程序记录的响应状态、时间、计数与错误 | 本次采集统计；不伪造 DSH 对话 |
| 选题 | 原生 DSH 输入、输出、工具调用与返回 | 全部候选及其引用的信号快照 |
| 写稿 | 原生 DSH 会话、稿件保存步骤 | 本次稿件正文、保存版本和质量报告 |
| 配音 / 字幕 | 配音与识别服务的实际状态、完成记录、任务标识、校对记录 | 可试听音频、SRT、识别诊断、字幕历史版本及项目同步结果 |
| 视频制作 / 质检 | 视觉导演和独立审片各自的 DSH 会话；预检、渲染、技术检查记录 | 成片、抽帧、技术报告、审片意见、创意工程与渲染日志 |
| 发布资料 / 封面 | 发布文案 DSH 会话；各封面服务提交与完成记录 | 文案、标题、描述、标签、封面提示词与封面图片；部分失败单独展示 |
| 内容安排 | 本轮选题及每个项目、阶段的具体任务引用 | 跳转同一详情面板；执行中与失败后仍能查看关联任务 |

会话按轮展示可折叠的执行过程，并根据 `user/message.source` 区分任务输入、上下文注入与上下文召回。系统指令、技能目录、工作区指令等注入记录保留真实来源和正文；未知来源也保持可见。模型返回且会话保存了 reasoning 时才展示“思考”行，历史预览取首行，实时预览取最新一行。工具行展示真实操作说明或文件路径，按轮次、步骤与 callId 关联参数和返回；原生嵌套 tool-result 的正文直接可读。历史分页暂缺调用时保留独立返回，加载更早记录后自动归并。整轮结束后，最终文本回复展示在过程区域之后。只有结构化工具结果的历史会话，展示工具结果，不补写推理，也不把上下文注入称为模型思考。旧服务任务没有保存的过程不会被补造；详情明确说明缺失。

## 数据和连接

- `spoken-video-execution.mjs` 按任务类型与 ID 解析能力包自有记录；浏览器无法指定任意会话或文件路径。
- Gateway 根据保存的 parent/child ID 构造原生 `subagent` 地址，调用 `sessionController.follow/page`。不会按普通对话地址激活父会话。
- 客户端通过 `remote.$mount` 注册该能力包的流式方法，复用原生 Gateway WebSocket 多路订阅；由 `remote.$stream` 管理连接恢复。常规浏览器的 `connection.rpc.open` 并非必定存在。
- 实时数据使用原生 assistant-stream 基线与分块序号；落盘后由消息事件替换临时内容。加载更早记录不会被之后的流事件覆盖。
- 任务输入和结果使用本次保存的快照。旧发布任务按 `resultRevision` 找不可变 packaging 产物，避免拿当前项目内容冒充历史结果。
- 新的媒体过程事件附加到业务记录；Remotion 完整输出写入该次工程的 `outputs/render.log`。配音、字幕在项目提交前保存已产出的媒体信息，提交冲突仍可查阅。
- 产物预览仅允许任务列出的文件，规范路径后限制在能力包数据目录，拒绝符号链接越界。文本预览上限 2 MiB，媒体上限 80 MiB；凭据字段、常见授权值及传输用 base64 块不展示。
- 账号定位完善新增 `account-generations.json`，启动时恢复中断状态。其余任务沿用各模块原有恢复机制。

## 交互与验收

详情使用原生模态层，避免移动端侧栏遮挡。桌面支持宽屏展开；390px 窄屏自动铺满。保留模块强调色、深色模式、Markdown 排版、可折叠工具详情与按需加载的媒体预览。Escape 关闭并恢复到入口按钮，键盘焦点限制在面板内。终态任务短暂补读后停止轮询；错误支持重新读取。

验证包括：真实历史选题与稿件的原生会话读取、展开工具参数、桌面与移动端截图、深色模式、Escape/焦点恢复；模拟原生流事件验证思考和正文增量、工具参数、历史分页保留、落盘去重与关闭订阅。测试未调用付费生成服务。

行为测试覆盖任务归属、路径/符号链接边界、历史版本、凭据过滤、原生流展开、分页与观察取消、账号历史及中断恢复；现有媒体和内容安排测试同时检查真实过程记录与失败阶段任务引用。
