# UI 巡检与使用就绪评估

> 历史设计/验收记录，包含当时的方案与限制，不作为当前使用指南。当前入口见[文档索引](README.md)和[快速开始](quickstart.md)。

巡检时间：2026-09-15 至 2026-09-16。

结论：本轮发现的字号、设置入口图标、布局与交互细节问题已修复，基础功能可进入人工监督下的试用。当前实际环境尚不能判定为“全流程正式投产就绪”：媒体凭据缺失，两个外部信号源请求失败，真实服务的完整生产链路仍需验收。

## UI 调整

- 工作台与口播视频能力包共用字号层级：辅助文字 12–13px、常规内容 14–16px、区块标题 18–20px、页面标题 24px。此前大量 9–12px 的文字已放大；稿件正文使用 16px。DSH 原生会话字号继续由“系统设置 → 通用设置”管理。
- “系统设置”入口使用 DSH 原生 SVG 齿轮；修正设置行中泛化 `span` 样式污染按钮、选择器未覆盖原生包装层的问题，使图标和文字正常横向排列。主导航和收起侧栏按钮也改用原生 SVG。
- 统一按钮与输入框尺寸，增加键盘焦点反馈；历史操作按钮支持键盘聚焦显示。导航增加可访问名称和当前页面标记。
- 加强辅助文字、暗色按钮和统计数字的对比度；侧栏可滚动，避免小窗口下菜单被挤压。
- 按实际内容宽度调整双栏、渠道卡片和视频工作区；手机下表单字号为 16px，标签栏可横向滚动。
- 去除能力包页面重复的介绍标题；修正手机抽屉与全局导航按钮重叠、抽屉底栏横向溢出。
- 设置页连接状态读取 DSH 的实际连接状态，不再固定显示“已连接”。

实现位于 `lwb/dsh-bundle/client.js` 和 `lwb/packs/spoken-video/client.js`。继续使用原生 DSH 设置、模型与认证，不增加重复配置体系，也未修改 vendor 上游代码。

实际实例 `127.0.0.1:3080` 用于只读巡检；账号、模型测试配置、项目与定时任务的写入均在 `127.0.0.1:14383` 的隔离实例完成，其 DSH home 和能力包注册表独立保存于 `.lwb/ui-audit/`。

| --- | --- |
| 页面入口 | 对话、场景能力包、设置，以及账号定位、信号、选题、写稿、配音/字幕、视频/预览、发布、内容安排均完成浏览检查 |
| 响应式与主题 | 检查 1280、900、390px 宽度；检查深浅色下的页面、设置入口、表单与抽屉 |
| 原生设置 | 通用设置、模型、插件、Agent 预设、已归档会话均可打开；语言与主题切换可用 |
| 能力包与账号 | 能力包从市场加载；创建账号后刷新仍保留；Agent 协助完善经过 DSH 和本地模拟模型返回结果 |
| 稿件与媒体展示 | 隔离夹具稿件可被配音/视频来源选择器读取；发布页可加载并解码 360×640、2 秒的本地测试视频 |
| 发布资料 | 修改标题、保存、刷新并重新打开，值正确保留；手机抽屉复查 |

| 自动化回归 | 最终 `npm test` 通过：264 项，0 失败、0 跳过；包含语法检查、产品与能力包 profile 检查、文件入口、隔离、业务状态和媒体流水线等测试 |
| 差异检查 | `git diff --check` 通过 |

最终 33 次页面宽度复查（11 个入口 × 3 档宽度）未发现页面横向溢出；配音页持续显示预期的凭据缺失提示。手机发布抽屉实测内容宽度与滚动宽度均为 389px，没有底栏溢出。结束时停止隔离服务，设置页从“已连接”变为重连状态；实际 3080 实例继续运行。

模拟模型验证的是 DSH 调用接线与数据流；夹具视频验证的是媒体读取、解码及资料展示。它们不能证明真实模型质量、真实 TTS/ASR/生图供应商可用性，也不能替代一次完整生产验收。

## 实际环境待完成事项

| 事项 | 当前证据与影响 | 正式使用前的验收 |
| --- | --- | --- |
| 默认模型 | 界面选中了 Qwen3.8-Max；本次未向其发起真实生产任务 | 实际完成一次账号辅助、选题和写稿，确认鉴权、额度与结果质量 |
| 配音与字幕 | 界面提示未配置 TTS 凭据，TTS/ASR 服务配置中缺少 API Key | 配置所选媒体服务，实际生成配音、对齐字幕，并检查音色、时长及时间码 |

| 信号采集 | Hacker News、AI 论文日报 · Hugging Face 显示“来源请求失败：fetch failed” | 检查本机到对应来源的网络与服务可用性，恢复后重新采集；现有错误信息不足以断定具体网络根因 |
| 完整生产链路 | 本次没有使用真实供应商跑完从选题到发布资料的生产任务 | 至少完成一条真实内容：选题 → 写稿并确认 → 配音字幕 → 渲染 → 质检 → 发布资料，人工检查全部产物 |

“发布”模块当前用于准备成片与发布资料，向外部内容平台提交仍由用户完成；本次未进行任何公开发布。当前验收面向本机单用户工作台，不代表多用户服务或长期无人值守运行已通过验收。
