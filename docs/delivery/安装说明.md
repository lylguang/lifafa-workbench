# 李发发工作台 · 安装说明

## 这个软件是做什么的

一个本地运行的 AI 内容生产工作台：从选题、写稿、配音字幕，到视频渲染、成片审片，再到发布资料与平台投递。所有数据和素材都留在你自己的电脑上。

## 开始之前

请确认这台电脑满足：

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 或 11（64 位） |
| 内存 | 至少 16GB，装本地配音建议 32GB 以上 |
| 硬盘 | 至少 30GB 空闲（渲染需要临时空间） |
| 其他软件 | [Node.js](https://nodejs.org/) 22 或 24、FFmpeg |

Node.js 和 FFmpeg 的安装方法见文末「装不上怎么办」。

## 三步启动

1. **解压**。把 zip 解压到一个固定目录，比如 `D:\工作台`。不要放在需要管理员权限的位置，也不要放在网盘同步目录里。
2. **双击 `自检.cmd`**。它会检查环境并给出配置建议。**这一步不要跳过**——绝大多数启动失败都是环境问题，自检会直接告诉你缺什么。
3. **双击 `启动工作台.cmd`**。浏览器会自动打开工作台。

> 关闭浏览器不会停止工作台。要彻底停止，关掉那个黑色的命令行窗口。

## 第一次使用需要配置什么

工作台不附带任何 AI 服务额度，所有 AI 能力都需要你自己的账号和密钥。

1. **设置 → 系统设置 → 模型**：添加一个模型服务商，填入你的 API Key，设为默认。
   - 写稿、视频制作、审片都用这个默认模型。
   - **审片环节需要模型能读图片**，请确认你选的服务商支持图像输入，否则审片一定失败。
2. **场景能力包**：找到「口播视频内容创作」，点「加载」。左侧会出现账号定位、选题、写稿等入口。
3. **配音 / 字幕 → 连接配置**：填入配音服务的凭据。
4. **发布资料 → 封面生图**（如果你打算用云端生图）。

配置一次就会记住，之后不用再动。

## 配音和封面：先跑通再优化

工作台默认使用**云端**配音和生图，这需要联网但不需要显卡。确认整条流程走通之后，再考虑要不要配置本地模型加速。

打开浏览器访问 `http://127.0.0.1:8199` 可以查看本机模型状态（只有本地增强版才有这个页面）。

**为什么不默认就配本地模型**：本地配音需要约 23GB 空闲内存和一块 8GB 以上的独立显卡，本地封面生图需要 12GB 以上显存。8GB 显存的电脑装不了封面生图，硬装只会让程序报错。先用云端跑通，确认这套东西对你有用，再决定要不要折腾本地模型。

## 建议的使用顺序

第一次用，按这个顺序走，每一步都确认没问题再进下一步：

1. 设置好模型，测试对话能通
2. 账号定位 → 写一个短视频脚本
3. 配音 + 字幕，确认音频和字幕正常
4. 视频制作，等渲染完成
5. 发布资料，生成标题和文案

完整说明见 `docs/quickstart.md` 和 `docs/troubleshooting.md`。

## 遇到问题

| 现象 | 怎么办 |
|---|---|
| 双击没反应 | 右键脚本 →「以管理员身份运行」 |
| 提示缺少 Node.js | 装 Node.js 22 LTS，安装时勾选「Add to PATH」 |
| 提示找不到 ffmpeg | 见文末 |
| 渲染很慢或失败 | 运行 `自检.cmd` 看浏览器检查结果 |
| 报「dsh web authentication required」 | 用 `启动工作台.cmd` 启动，不要手动开裸地址 |
| 视频渲染报磁盘空间不足 | 清理磁盘，或设置环境变量 `LWB_SCRATCH_ROOT` 指向一块空间大的硬盘 |

更详细的问题排查见 `docs/troubleshooting.md`。

## 数据和隐私

- 你的稿件、成片、账号信息**全部保存在本机**：`lifafa-workbench\lwb\local\`。程序不会把这些上传到任何服务器。
- 唯一会联网的地方是：你主动发起的 AI 请求（写稿、生成配音等），以及你配置了云端生图/配音时的第三方服务。这些请求会包含你的稿件内容。
- 发布功能会用你本机 Chrome 的登录状态向平台投递内容，请只对你自己的账号使用。

**备份**：把 `lifafa-workbench\lwb\local\` 整个目录复制走就是完整备份。重装或迁移前记得先备份。

## 装不上怎么办

**Node.js**：去 <https://nodejs.org/> 下载 22 或 24 的 LTS 版本，安装时确保勾选 "Add to PATH"。装完打开命令行输入 `node -v` 能看到版本号就成了。

**FFmpeg**：去 <https://ffmpeg.org/download.html> 下载 Windows 版本，解压后把 `bin` 目录加入系统 PATH。或者用包管理器：`winget install Gyan.FFmpeg`。

两个都装完后**重新运行 `自检.cmd`** 确认。
