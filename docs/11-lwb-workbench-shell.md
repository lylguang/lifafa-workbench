# 11 LWB 工作台壳

> 历史设计/验收记录，包含当时的方案与限制，不作为当前使用指南。当前入口见[文档索引](README.md)和[快速开始](quickstart.md)。

> **状态（2026-08-31）**：产品导航只显示“对话”“场景能力包”和“设置”；已加载场景包可在该导航下增加自己的菜单。

## 可见模块

| 导航 | 界面 | 关键规则 |
|---|---|---|
| 对话 | 普通 Session 历史、搜索、新建、工作区与官方 DSH Conversation | 会话、工作区与归档保持 DSH 原生边界 |
| 场景能力包 | 可搜索、筛选的市场卡片、详情抽屉与菜单注入 | 市场只检查 manifest；加载/卸载由 DSH Loader 在当前页面动态切换，保留市场内容并更新菜单 |
| 设置 | 工作台设置页，通过“系统设置”打开完整的 DSH 原生设置面板 | 服务商、模型、凭据、语言、主题、工具和审批由 DSH 管理 |

LWB 在 DSH `sidebar` slot 提供主导航，在 `shell.overlay` 提供会话列表、管理页和“设置”页中的原生 settings seat。官方 DSH 仍控制 Session 创建、Conversation 渲染、详情、轨迹、模型、凭据、工具和权限。

## 设置入口

设置页使用“基础配置 → 系统设置 → 打开设置”，页面说明为“管理工作台的系统配置与偏好”。该入口复用 `sidebar.settings` 原生插槽，打开完整面板，涵盖通用设置、模型、插件、Agent 预设与已归档会话；它不是只进入模型页的快捷入口。DSH 的技术来源在“关于”中说明。

普通对话和能力包内部会话的模型配置均由 DSH 管理，能力包新建内部会话时读取 DSH 默认模型及认证。TTS、ASR、封面生图等业务连接仍在对应业务页面配置。缺少默认模型时，提示用户前往“设置 → 系统设置 → 模型”。

## 存储与刷新

- 浏览器仅持久化当前页面、外观和语言相关偏好；市场目录由 host `lwbPacks/market` 提供，左侧只读取运行中的 `lwbPacks/list`。
- 对话列表、搜索、工作区和归档列表均使用 DSH 原生会话数据。
- 场景能力包的 host/client 入口、菜单和数据模型均由包自身拥有；核心壳只负责目录与页面插槽。首个口播视频包的阶段工件留在当前 DSH 会话工作区。
