# 本地媒体桥接 · 使用说明

这个目录是李发发工作台的本地模型适配层：把工作台的配音、字幕、封面生图接到本机 ComfyUI 模型上，**零云端费用**。

## 它接了什么

| 功能 | 本地引擎 | 位置 |
|---|---|---|
| 配音（含声音克隆） | LongCat-AudioDiT-3.5B | E:\ComfyUI-CZX（绘世启动器，端口 8188） |
| 字幕识别 | Qwen3-ASR-1.7B | 同上 |
| 封面生图 | Qwen-Image-2.1（20B int8） | E:\Qwen-Image-2.1-Pose\Qwen-Image-2.1（内部 ComfyUI，端口 8187） |

桥接服务本身：`bridge.mjs`，监听 `http://127.0.0.1:8199`。**浏览器打开 http://127.0.0.1:8199 就是配置中心**：配音模型参数、音色库管理（上传/试听/试合成/删除）、系统默认音色映射都在这里，保存立即生效。它同时说两套协议：工作台界面选「**SciTiger 云端**」就能直连本地模型；封面走「百炼」渠道同样指向本机。

## 生成状态与进度

配置中心顶部的「生成状态与进度」面板每 2 秒自动刷新：

- 每个任务（配音/字幕/生图）显示状态（排队/执行中/完成/失败）、当前阶段、实时百分比、用时
- 进度来自 ComfyUI 的实时事件流：模型加载后合成/渲染阶段能看到真实百分比；排队或准备阶段显示流动进度条
- 完成的任务直接在结果列试听音频、看封面缩略图、下载 SRT 字幕
- 面板底部显示两个引擎的队列占用（几条运行/几条排队）

## 配置中心能配什么

| 配置 | 说明 |
|---|---|
| TTS 模型 | LongCat 档位（3.5B-bf16 已装推荐；1B/fp8 需联网下载） |
| 步数 / 引导强度 / 引导方式 / 注意力 | 合成质量与速度的平衡，一般不用动 |
| 字幕 ASR 模型 | Qwen3-ASR-1.7B（已装推荐）/ 0.6B |
| 「系统默认」音色映射 | **核心功能**：工作台配音界面选“Tiffy - 自信（系统默认）”时，实际使用的音色。在这里选定后，工作台里不用每次上传参考音频 |
| 音色库 | 上传（建议 8~15 秒干净人声）、试听、一键试合成、删除；音色 ID 即文件名 |

高级：每个音色可建 `voices/ID.json` 覆盖全局参数，格式 `{"tts":{"model":"…","steps":24}}`（如某音色用 1B 模型提速度）。

## 启动顺序

1. **配音/字幕**：双击绘世启动器启动 ComfyUI-CZX（到端口 8188 即可）。
   **也可以不手动开**：桥接收到配音/字幕任务时会自己把 8188 拉起来（约 20 秒），
   定时任务因此不需要有人值守。
2. **封面生图**：需要生图时，双击 `E:\Qwen-Image-2.1-Pose\Qwen-Image-2.1\开始.bat`。
   **同样可以不用手动开**：桥接收到生图任务时会自己拉起来。
   ⚠️ **配音和生图共用 16G 显存，装不下两个大模型同时驻留**：做完配音再做生图没问题（模型用完自动释放），但反过来"生图应用开着不关就去配音"会报"页面文件太小"(os error 1455)——把 Qwen-Image 窗口关掉再配音即可。
3. 双击 `lifafa-workbench-main\启动工作台.cmd`——它会自动先拉起本桥接，再启动工作台。

> **无人值守（定时任务）**：计划任务 `LWBKeepAlive` 每 5 分钟检查工作台(4173)与
> 桥接(8199)，掉线就自动拉起；两个 ComfyUI 引擎由桥接在任务到达时按需启动。
> 开机后约 3 分钟首次运行，所以重启机器不需要人工干预。
> 想临时停用保活：新建空文件 `E:\lifa-scratch\lwb-keepalive.off`。

## 工作台里的设置（一次性）

- **配音 / 字幕 → 连接配置**：服务渠道选「**SciTiger 云端**」，API Key **随便填一串字符**（如 `local`）并保存——本机服务不校验，但界面要求有凭据才放行。
- **封面生图**：封面服务选「百炼」，API Key 同样随便填，模型名随意。
- 「兼容 TTS 服务」选项不要用：工作台这个界面对它支持不完整（生成按钮过不了凭据检查），已被 SciTiger 渠道取代。

## 音色

- **配置中心（http://127.0.0.1:8199）**：上传音色、试听、试合成、删除，以及把「系统默认」映射到你选的音色——映射后工作台配音界面选“系统默认”就是你的声音。
- **上传参考音频**：配音面板选「上传自己的参考音频」，传 8~15 秒干净人声即可克隆。
- 首次使用某参考音频会多等十几秒（自动转写），之后有缓存。

## 注意事项

- **长稿配音已自动分段**：LongCat 单次只能清晰合成短句，桥接会按句切成 ≤100 字的段逐段合成再拼接（段间 200ms 停顿）。1134 字长稿约 12 段、2~3 分钟完成，效果清晰；配置中心的进度条会显示「分段合成 i/N」。
- 工作台配音/字幕渠道选「**远端 · SciTiger**」（`启动工作台.cmd` 已把该渠道地址指向本机桥接），API Key 随便填；封面选「百炼」+ 随便填 Key。**两条渠道都指向本机，零云端费用。**
- ⚠️ 环境变量 `LWB_SPOKEN_VIDEO_SCITIGER_BASE_URL=http://127.0.0.1:8199` 必须在启动工作台时设置，否则 SciTiger 渠道会连到真云端报 "Invalid API key"（启动工作台.cmd 已包含，手动启动时务必带上）。
- 桥接会自动把任务排队串行执行（两个模型同时加载会撑爆内存提交上限）。
- 语速/音量参数已支持；音高调整 LongCat 暂不支持。
- 桥接日志：`data\bridge.log`；任务与产物：`data\` 目录。
- 保活日志：`E:\lifa-scratch\lwb-keepalive.log`（只在需要拉起时才写）。
- 遇到 os error 1455 = 显存/内存不够：关掉 Qwen-Image 应用或其他大程序后重试。
- 显存余量不足时「一键启动」仍会尝试（只提示不拦截）：Windows 会调度让出显存，
  实测只剩 2 GB 时 8188 照样能起来并跑完字幕。**内存**不足则真的会被系统杀掉，
  那种情况会直接拦下并说明原因。
