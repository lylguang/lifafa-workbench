# 白板手绘动画能力包

把 SRT 字幕做成暖米黄纸张底的白板手绘动画：按字幕叙事顺序逐区域落墨，笔尖沿线条连续走线、先铺线稿再上色，最后停留在完整画面上。

## 它解决什么问题

白板手绘视频的常见做法是"整张图从无到有画出来"，无法控制**哪个元素先出场**。本包用字幕的叙事顺序驱动绘制顺序：字幕讲到假山就先画假山，讲到猴子再画猴子。

两层正交设计：

- **编排层（mask）**：每个元素是一个矩形 `region`，带 `sequence`（叙事序号）与 `reveal.startMs`（出场时刻）。区域的允许作画掩码 = 自己的 `region` 扣除「所有后续区域的 `region`」再扣除 `protectedRegions`。**纯几何减法实现出场顺序**，不需要语义分割，因此后画的区域不会提前露线。
- **画法层（stream）**：在每个区域自己的允许掩码内，笔尖沿骨架/网格连续滑行落墨（`ink` 铺线稿 → `color` 还原原色，权重 2:1）。所有区域共享一张持久画布，画完的保留在画布上。与逐格跳变或矩形擦除相比，笔迹是连贯流动的。

## 页面

- **场景**：新建项目、解析字幕给出分幕建议、查看各幕的标注概况。
- **渲染**：准备引擎环境、逐幕渲染 MP4、多幕合并。

## 与口播管线的衔接

本包与「口播视频内容创作」包的配音字幕阶段直接衔接。口播包产出的是**经过时间轴守卫校正的 SRT**（能量 VAD + 发音字符占比铺排 + 本地 ASR 锚点校正），时间戳已对齐真实音频。

对接方式：把该 SRT 作为「解析字幕」的输入；每幕的 `sceneDurationMs` 取该幕字幕跨度；每个区域的 `reveal.startMs` / `durationMs` 对齐到对应字幕的起止时间，并把字幕文本写进 `element.subtitle`。

这样"第几秒画哪个元素"来自**字幕时间轴查表**，而不是凭感觉猜秒数。Agent 拿不到语音时间轴时只能猜秒数，容易造成画面超前或滞后；这里每个区域的出场时间是显式写在 JSON 里、可在预览台拖拽微调的。

## 使用前提

1. **Python 环境**：首次在「渲染」页点「准备环境」，会在包内创建隔离的 `.venv` 并安装 OpenCV、NumPy、Pillow。这一步只做一次。
2. **线稿图**：由 Agent 按技能文档里的统一视觉规范生成（极简手绘、暖米黄纸底 `#F5EBD7`、画面不出现任何文字）。
3. **ffmpeg（可选）**：存在时优先用它转 H.264，体积最优；否则退回 PyAV。

渲染是纯 CPU 计算，不需要 GPU 或联网。实测 1080p 约 19 帧/秒，3 分钟成片约需 9–10 分钟。

## 目录结构

```text
whiteboard/
  lwb-pack.json                       # 能力包清单
  index.mjs                           # host 入口
  gateway.mjs                         # 前后端 RPC 桥
  whiteboard-store.mjs                # 项目与标注持久化
  whiteboard-host.mjs                 # 编排层：调用 Python 引擎
  client.js                           # 浏览器页面
  skills/srt-whiteboard-animation/    # Agent 技能文档（工作流与硬约束）
  engine/                             # 打过补丁的渲染引擎（见 engine/PATCHES.md）
  test/whiteboard.test.mjs            # 单元测试
```

## 引擎来源

引擎是 `geeklee/srt-whiteboard-animation`（MIT）的 vendor 副本。上游自 2026-07-27 发布后未再更新，已知缺陷的修复仍停留在未合并的社区 PR 里，因此这里直接落在源码上。补丁清单与理由见 `engine/PATCHES.md`，要点：

- 修复了区域允许掩码为空时必崩的 `TypeError`（区域重叠是正常用法，原版必崩）
- 新增渲染前输入校验（坐标越界、非整数、缺字段）
- 字幕分幕改为动态规划，不再产生短幕
- 检查图脚本改为跨平台字体探测
- 默认绘制手部素材已清除上游作者的笔杆标识，并新增 `--pen-text` 支持自定义

## 数据位置

项目与标注位于能力包专属工作区的 `data/` 下：

```text
data/projects.json                      # 项目索引
data/projects/<project-id>/
  scene-01-<名称>.annotation.json       # 标注（与图片同名）
  out/scene-01-<名称>-whiteboard.mp4    # 成片
```

卸载能力包会保留工作区与数据。
